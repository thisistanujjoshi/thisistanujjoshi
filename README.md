## 🚀 About Me

I'm a **self-taught software engineer** who learns by shipping. Instead of tutorials, I build complete, deployed systems across the stack — web apps, AI agent pipelines, and the infrastructure that runs them — then dig into *why* things break in production.

- 🔐 Currently deep in **application security** — practicing OWASP Top 10 exploitation and remediation alongside PortSwigger's Web Security Academy
- 🤖 Building **multi-agent LLM systems** that reason through real problems (system design, content pipelines) rather than just chaining prompts
- ☸️ Learning **Kubernetes** hands-on by running real workloads on a local cluster, not just reading the docs
- 🛠️ I write up the debugging stories, not just the finished demo — config bugs, deploy failures, and the actual fix

---

## ⚙️ What I Build

### 🔐 Application Security
Deliberately-vulnerable apps built to practice finding and fixing real bugs: SQL injection, stored XSS, and broken authentication — each documented with the CWE, the exploit, and the fix.

### 🤖 AI Agent Systems
Multi-agent LLM pipelines that break a hard problem into stages — research, planning, generation, self-critique, revision — instead of a single prompt-and-hope call.

### 🌐 Full-Stack Web Apps
End-to-end apps taken through to real deployment (Vercel, Render), including the config and infra bugs that only show up once something's actually live.

### ☁️ Infrastructure & Platforms
Distributed systems and platform tooling — microservices, Kubernetes deployments, Terraform-managed infra, and observability with Prometheus/Grafana.
